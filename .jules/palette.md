## 2024-05-18 - Avoid onClick on non-interactive semantic elements for navigation
**Learning:** Attaching `onClick` handlers to non-interactive elements like `<article>` for primary navigation (e.g., product cards, registry items) creates significant accessibility barriers. Screen readers may not announce them as interactive, and keyboard users cannot focus or activate them using Enter/Space without explicit `tabindex` and keydown listeners. Even with ARIA attributes, standard navigation behavior (like opening in a new tab) is lost.
**Action:** Always wrap non-interactive semantic elements like `<article>` in React Router `<Link>` or standard `<a>` tags. Use CSS resets (`textDecoration: 'none'`, `display: 'block'`, `color: 'inherit'`) on the link element to maintain the desired visual design while preserving native focus management, semantic meaning, and expected browser navigation behavior.
