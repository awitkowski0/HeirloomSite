## 2025-06-11 - MiniSearch Index Recreation Anti-pattern
**Learning:** In `src/lib/search.ts`, the `MiniSearch` index was being synchronously recreated from scratch on every invocation of `searchProducts()`, which caused a performance bottleneck when filtering products because the entire inventory was re-processed every keystroke.
**Action:** When working with client-side search libraries like `MiniSearch`, always implement a module-level or singleton cache for the built search index keyed by the source data (e.g., using reference equality `cachedInventory === inventory`), to prevent redundant O(N) index generation on successive searches.
